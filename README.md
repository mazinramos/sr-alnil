# سرّ النيل

لعبة ألغاز عربية للهاتف والمتصفح، تدور حول **نور** التي تفتح غرفة جدّتها صفية وتتبع خريطة ممزقة على امتداد النهر. **35 مستوى** في **5 فصول** (القرية القديمة، جزيرة الأسرار، سوق الحكايات، أطلال النهر، الضفة الهادئة) و**12 نوع لغز**: بحث، ترتيب، ربط، قفل رموز، اختيار، مسار، ميزان، قطع، ذاكرة، شفرة، استنتاج، وتركيب. واجهة كاملة من اليمين لليسار، تعمل باللمس أولاً، بلا مؤقت ولا فشل نهائي، مع ثلاثة تلميحات لكل مستوى ونجوم من 1 إلى 3. التقدّم يُحفظ محلياً في المتصفح.

## التشغيل محلياً
المطلوب: **Node.js 22 أو أحدث** وGit.
```
git clone https://github.com/mazinramos/sr-alnil.git
cd sr-alnil/artifacts/nile-secrets
npm ci
npm run dev        # http://localhost:5173
```
| الأمر | ماذا يفعل |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run check` | فحص TypeScript ثم البناء إلى `dist/` |
| `npm run preview` | تجربة النسخة المبنية |
| `npm run verify` | الفحص الشامل بأمر واحد (بلا e2e) |

أدوات المطوّر `#/preview` (معاينة الألغاز) و`#/preview/coords` (أداة الإحداثيات) تعمل مع `npm run dev` فقط، ولا تظهر في النسخة المنشورة.

## بنية المجلدات
```
artifacts/nile-secrets/        التطبيق (Vite + React 19 + TypeScript + Tailwind v4)
  src/engine/                  المحرّك: المستويات، التقدّم والتخزين، الشاشات، الصوت، التوجيه
  src/puzzles/<نوع>/           مكوّن كل نوع لغز + demo.ts
  src/content/                 الأنواع المشتركة types.ts وملف بيانات لكل فصل chapters/chN.ts
  src/styles/                  تصميم الواجهة
  public/art/                  الصور (خلفيات، شخصيات، أيقونات، مصغّرات)
  scripts/                     أدوات الفحص والصور
docs/                          العقد، المستويات، التوجيه الفني، النشر، الفصول المرجعية للتقرير
```
اللعبة قائمة على البيانات: المستوى كائن في `content/chapters/` يستعمل نوع لغز جاهزاً، فإضافة مستوى أو فصل لا تحتاج تعديل المحرّك (انظر `docs/ADD_CHAPTER.md`).

## البناء والنشر
الموقع ثابت بلا خادم، يُنشر على Vercel من المجلد `artifacts/nile-secrets` (الأمر `npm run build`، المخرج `dist`)، ويُحدَّث تلقائياً مع كل دفعة إلى `main`. الخطوات المفصّلة في [`docs/DEPLOY.md`](docs/DEPLOY.md).

## الاختبارات
كلها من داخل `artifacts/nile-secrets/`:
- `npm run test:unlock`: قواعد فتح المستويات والفصول.
- `npm run test:migrate`: ترحيل التقدّم القديم وسلامة التخزين (غير متاح، ممتلئ، تالف).
- `npm run test:content`: فاحص المحتوى (بنية المستويات، قابلية الحل، الشخصيات، منع الإيموجي) مع اختبار ذاتي.
- `npm run test:thumbs`: أداة المصغّرات.
- `npm run test:e2e`: يحلّ المستويات الـ35 على عرض هاتف بمتصفح Playwright (ينزّل المتصفح عند أول تشغيل).
- `npm run verify`: يشغّل ما سبق عدا e2e مع فحص المصغّرات وملخص الصور، ويقف عند أول فشل.

قائمة الفحص قبل التسليم، ومنها الفحص اليدوي على الأجهزة، في [`docs/RELEASE_CHECKLIST.md`](docs/RELEASE_CHECKLIST.md).

## الاعتمادات والترخيص
- **الصور مولَّدة بالذكاء الاصطناعي** (أدوات توليد صور خارجية) بتوجيه فني مكتوب في `docs/ART.md`، ثم حُوّلت إلى WebP. لا تُعدّ أعمالاً يدوية.
- **النصوص والكود** كُتبت بمساعدة نموذج ذكاء اصطناعي (Claude من Anthropic) تحت إشراف الفريق ومراجعته. القصة والشخصيات والأماكن متخيَّلة، ولا تدّعي حقائق تاريخية.
- **الخطوط:** Cairo وNoto Sans Arabic وNoto Serif Arabic وIBM Plex Mono من Google Fonts (ترخيص OFL).
- **الأيقونات:** lucide-react.
- **الترخيص:** لم يُحدَّد ترخيص مفتوح بعد؛ القرار لصاحبة المشروع. إلى حين ذلك لا يُعاد استعمال الصور أو النصوص خارج هذا المشروع.
