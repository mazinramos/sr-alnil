# منهج العمل وطبقات المراجعة

## الأدوات المستخدمة
| الفئة | الأداة | الاستخدام |
|---|---|---|
| البرمجة | VS Code وTypeScript وVite | بناء المشروع وتشغيله |
| الكتابة والبرمجة | أدوات مساعدة ذكية | مسوّدات الكود والنصوص والوثائق، تُراجَع بعد ذلك وتُختبر |
| الصور | أداة توليد صور | الخلفيات والشخصيات والأغراض، من توجيه مكتوب لكل صورة |
| الإدارة | Git وGitHub | تاريخ المشروع وحفظ الشيفرة |
| النشر | Vercel | استضافة ونشر تلقائي |
| الاختبار | Playwright | لعب آلي كامل في متصفح حقيقي |

بقي بيد صاحب المشروع الفكرة والاتجاه، وقبول كل صورة أو رفضها، والقرارات التي تغيّر المنتج، والتجربة على جهاز حقيقي. ولم يُعتبر شيء منجزاً قبل أن يمرّ بفحص آلي أو بمراجعة.

## كيف نُظّم العمل
- **مواصفات فنية مكتوبة:** تثبّت الأنواع والبنية وأسماء الملفات ومقاسات الصور وأسلوب الكتابة، فلا يتعارض جزءان من المشروع.
- **المحتوى بيانات لا كود:** تُكتب الفصول دون المساس بالمحرّك.
- **تاريخ git:** أكثر من 110 commit، كل واحد برسالة تصف ما تغيّر.
- **بوابات زمنية:** معاينة المحرّك وكل أنواع الألغاز، ثم دمج كل ما هو جاهز وقابل للّعب، ثم تجميد لا يدخل بعده إلا إصلاح خطأ يوقف اللعب.

## طبقات المراجعة
1. **فاحص المحتوى:** يرفض المستوى بلا دلائل كافية أو بحلّ مستحيل أو بتلميحات غير ثلاثة أو بشخصية غير معرّفة أو برمز قد يظهر إيموجي ملوّناً.
2. **قراءة لاعب:** تُقرأ مستويات كل فصل كلاعب لا يعرف الحل، ويُسجَّل التلميح الذي يكشف الجواب أو الدليل غير المفهوم.
3. **مراجعة وصف الصور مقابل الدلائل:** تُطابق كل صورة بدلائل مستواها قبل التوليد.
4. **فاحص اللهجة:** يلتقط الفصحى والمفردات غير السودانية.
5. **لعب آلي كامل:** يمرّ على المستويات الخمسة والثلاثين في متصفح حقيقي بحلولها الصحيحة وبأخطاء متعمَّدة.
6. **تدقيق الحقائق:** كل رقم في الملفّات يُقارن بنتيجة أمر شغّلناه فعلاً.

## أخطاء حقيقية وجدناها وعالجناها
| المشكلة | كيف عولجت |
|---|---|
| صورة لا تطابق الدلائل (c3-l5): اللغز يطلب خيطاً وإبريقاً والصورة خرز وجرس | أُعيد بناء اللغز على ما في الصورة، وصارت القاعدة: ما يعتمد عليه اللغز يُكتب في وصف الصورة قبل التوليد |
| تلميح يكشف الحل مباشرة | أُعيدت صياغة التلميحات لتتصاعد تدريجياً |
| صورة (c5-l3) لا يظهر فيها خط النهر الذي يقوم عليه اللغز | أُعيد توليدها بخط ظاهر وأُعيد قياس الإحداثيات |
| رموز تظهر إيموجي ملوّناً على الهاتف | استُبدلت بأشكال هندسية وأُضيف فحص آلي يمنعها |
| لغة الواجهة والمحتوى فصحى | حُوّلت إلى الدارجي السوداني بقواعد مكتوبة وفاحص، دون المساس بأي حل |
| تعارض مفردات (الماء/الموية، الغرفة/الأوضة) | قرارات توحيد مكتوبة في دليل الأسلوب |
