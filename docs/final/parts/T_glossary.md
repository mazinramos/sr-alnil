# مسرد المصطلحات

| المصطلح | معناه في مشروعنا |
|---|---|
| **المحرّك (Engine)** | الجزء الذي يعرف كيف يعرض أي مستوى ويتحقق من حلّه، دون أن يعرف محتواه |
| **المستوى (Level)** | وحدة اللعب: حوار وهدف ودلائل وتلميحات ولغز ونتيجة |
| **اللغز (Puzzle)** | التفاعل نفسه، من اثني عشر نوعاً |
| **الدلائل (Clues)** | معلومات مكتوبة على الشاشة تكفي لحلّ المستوى |
| **التلميح (Hint)** | مساعدة اختيارية بثلاث درجات متصاعدة |
| **المحتوى كبيانات (Data-driven)** | كتابة المستويات في ملفات بيانات يقرؤها المحرّك بدل كتابتها كشيفرة |
| **TypeScript** | لغة برمجة تضيف الأنواع إلى JavaScript فتكتشف الأخطاء قبل التشغيل |
| **React** | مكتبة بناء الواجهات من مكوّنات صغيرة قابلة للتركيب |
| **Vite** | أداة التطوير والبناء السريعة |
| **Tailwind CSS** | طريقة كتابة التنسيق بأصناف صغيرة داخل العناصر |
| **التوجيه بالـhash (Hash router)** | التنقل بين الشاشات عبر الجزء بعد `#` في الرابط، فلا يحتاج الخادم إعداداً |
| **localStorage** | مخزن صغير في المتصفح يُحفظ فيه التقدّم على جهاز اللاعب |
| **E2E** | اختبار يلعب اللعبة كاملةً بمتصفح آلي كما يلعبها إنسان |
| **Playwright** | أداة تشغّل المتصفح آلياً للاختبار |
| **Git / GitHub** | نظام حفظ تاريخ المشروع، ومنصة استضافة شيفرته والتعاون عليه |
| **Vercel** | منصة الاستضافة التي تنشر اللعبة تلقائياً عند كل تحديث |
| **RTL** | الكتابة من اليمين إلى اليسار |
| **WebP** | صيغة صور مضغوطة بجودة جيدة وحجم صغير |
| **Deploy (نشر)** | رفع النسخة الجاهزة إلى الإنترنت |
| **الدارجي السوداني** | لهجة السودان العامية التي كُتب بها الحوار والدلائل |
