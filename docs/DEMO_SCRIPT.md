# DEMO_SCRIPT — عرض «سرّ النيل» أمام اللجنة (6 دقائق)
**جُرِّب هذا السيناريو آلياً** على شاشة 1280×720: المستويات الستة تُحَلّ بالترتيب نفسه بلا أخطاء، والصور تُحمَّل. **الأزمنة تقدير** لم يجرّبه شخص بعد؛ مازن يقيسها في بروفة واحدة.

## قبل العرض (5 دقائق)
1. افتح الرابط على الجهاز الذي سيُعرض عليه، وافتح تبويباً ثانياً بالنسخة المحلية (القسم الأخير).
2. **حفظ تجريبي:** ألصق في وحدة التحكم (F12 ← Console) ثم Enter. يكمل الفصول 1–3 ما عدا المستويات الستة المعروضة:
```js
(() => { const d = {}; for (const c of [1,2,3]) for (let l=1;l<=7;l++) d[`c${c}-l${l}`] = {stars:2,hints:0,attempts:1};
  for (const id of ["c1-l1","c1-l7","c3-l2","c3-l3","c3-l4","c3-l7"]) delete d[id];
  localStorage.setItem("nile-secrets-progress-v2", JSON.stringify({version:2,completed:d,discoveredClues:[],lastLevel:"c1-l1",settings:{sound:true,textScale:1}}));
  location.hash = "#/"; location.reload(); })();
```
3. **صرّح للجنة** بجملة واحدة: «جهّزنا حفظاً يتخطى المستويات التي لا نعرضها، فلذلك يظهر 21 من 35». هذا ليس تقدّماً لعبناه.
4. **لا تفتح** مستويات الفصول 2 و4 و5 (صورها لم تصل بعد، تظهر خلفية بديلة).

## ما يظهر وأين
**النجوم:** تظهر عند كل نجاح (ثلاث نجمات بلا تلميحات). **الدفتر (دفتر نور):** من الزر أعلى الشاشة، يضم دلائل ما لُعب. **الحقيبة:** قطع الخريطة والرموز. **الخريطة:** `#/map`.

## إن تعطّل شيء
- **الإنترنت أو الاستضافة:** افتح النسخة المحلية. جهّزها قبل العرض على الجهاز نفسه: `npm run build && npx vite preview` ثم `http://localhost:4173`. تعمل بلا إنترنت، لكن الحفظ التجريبي يُعاد لصقه لأن الحفظ مرتبط بالرابط.
- **الجهاز:** شغّل الرابط من هاتف احتياطي. وإن تعذّر كل شيء فاعرض اللقطات الجاهزة في `docs/demo_screens/` (20 صورة بأرقام تطابق الخطوات: `01_c1-l1_*` ثم `02_c1-l7_*` ثم `02_reward1` ثم `03_c3-l2_*` وهكذا حتى `09_inventory`).
- **مستوى بعينه توقف:** انتقل للتالي برابطه (`#/level/c3-l3`) ولا تحاول الإصلاح أمامهم. أو افتح اللغز منفرداً: `#/preview/jigsaw` أو `hotspot` أو `deduction` أو `balance` أو `memory` أو `cipher` (بدون حفظ).
- **أخطأتَ في لغز:** الرسائل هادئة ولا عقوبة. اضغط التلميح بهدوء؛ هذا جزء من العرض.
- **بعد العرض:** `localStorage.removeItem("nile-secrets-progress-v2")` ثم أعد التحميل لحذف الحفظ التجريبي.

## ما لم نجرّبه
لم يُجرَّب السيناريو مع شخص حقيقي ولا على الجهاز النهائي، ولا مع شاشة عرض أخرى غير 1280×720. اللمس الحقيقي غير مختبر (البروفة بالماوس).
