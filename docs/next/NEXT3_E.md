# NEXT3_E — دليل التوسّع إلى 100 مستوى
قراراتي: كلمة c4-l3 «النهر يعود» لا تتعارض (ذاكرة محجوزة لـ c5-l6 فقط). c4-l5 مقبول؛ الحل من ترتيب الرحلة الذي تعرضه الخريطة. تسمية الحراس الجدد مقبولة.
## قبل ما تبدأ
`git pull --rebase origin main`. نفس START والتوكن. اعمل في ملفاتك فقط. قبل كل push: `npm run typecheck` ثم `npm run check` ثم `npm run test:content` (بعد آخر rebase). ارسل التقرير بالقالب. **مواعيد:** أول دفعة السبت 14:00، الكل السبت 22:00، G2 الأحد 12:00.
**كل المستويات الـ35 موجودة الآن. من هنا الشغل: جودة، اختبار، توثيق. الصور تصل من مازن قريباً.**

**المهمة:** جعل إضافة الفصول بعد التسليم سهلة وآمنة، لأن عميلتنا قالت «ممكن نطوّرها بعدين لـ 100».
1. **`docs/ADD_CHAPTER.md`** بالعربية خطوة بخطوة (مثال مكتمل: «الفصل 6»): نسخ قالب، أسماء الملفات، `mapPiece`، الشخصيات الجديدة (CHARACTERS وصورها)، الخلفيات والأيقونات (الأسماء والمقاسات)، الرمز الجديد (SYMBOLS)، ما يتغيّر في خريطة الرحلة (الآن 5 محطات)، وكيف يتحقق الفاحص `test:content`.
2. **`artifacts/nile-secrets/src/content/chapters/_template.ts.txt`:** فصل قالب بسبعة مستويات (نوع لغز لكل مستوى) بتعليقات عربية لكل حقل وما يجب أن يتحقق منه الكاتب. ملف نصي حتى لا يُحمَّل في اللعبة.
3. **`scripts/new-chapter.mjs <رقم>`:** يولّد `chN.ts` من القالب بالأرقام والمعرّفات الصحيحة. لا يكتب فوق ملف موجود.
4. **قائمة «ماذا يعمل فعلاً عند 100 مستوى؟»:** اقرأ `engine/` وقل ما الذي سينكسر عند الفصل 6 وما بعده (CHAPTERS ثابتة = 5 في store، ChapterSelect بخمس محطات، ALL_LEVEL_IDS، التصميم). **لا تعدّل المحرّك**؛ اكتبها في `docs/EXPANSION_GAPS.md` مع تقدير جهد لكل بند، وB سينفّذها لاحقاً بعد التسليم.
