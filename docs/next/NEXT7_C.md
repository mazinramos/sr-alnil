# NEXT7_C — متانة اللعبة (مقاسات وانقطاعات)
## قبل ما تبدأ
`git pull --rebase origin main`. نفس START. اعمل في ملفاتك فقط. قبل كل push: `npm run typecheck` ثم `npm run check` ثم `npm run test:content`. التقرير بالقالب المعتاد. مواعيد: السبت 22:00 كل شيء مدفوع، G2 الأحد 12:00، G3 الاثنين صباحاً. لا ميزات جديدة.

شكراً. دليل 3 في c1-l5 يبقى كما هو.
1. **مصفوفة المقاسات:** شغّل جولة e2e قصيرة (مستوى من كل نوع من الـ12 يكفي) على: 360×640 و390×844 و412×915 و768×1024 و1280×800. لكل مقاس: تمرير أفقي؟ نص مقصوص؟ هدف لمس <44px؟ أبلغ بجدول، وأصلح ما كان في ملفاتك وارفع الباقي لصاحبه.
2. **انقطاعات اللاعب:** سيناريوهات آلية: (أ) إعادة تحميل الصفحة وسط مستوى ثم المتابعة، (ب) زر الرجوع بين الشاشات، (ج) ضغط مزدوج سريع على «تأكيد» و«تلميح»، (د) تغيير اتجاه الشاشة وسط لغز سحب، (هـ) تبديل التبويب ثم العودة. أي انهيار أو نجوم مكرّرة أو تقدّم مفقود: سجّله.
3. **شبكة بطيئة:** بمحاكاة 3G عبر CDP: كم ثانية حتى تظهر `#/` و`#/map` وأول مستوى؟ أبلغ بالأرقام (لا تعدّل شيئاً، للتقرير).
4. حدّث `docs/report/06_qa.md` بالنتائج الحقيقية فقط.
