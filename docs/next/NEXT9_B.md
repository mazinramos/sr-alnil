## قبل ما تبدأ
`git pull --rebase origin main`. اعمل في ملفاتك فقط. قبل كل push: `npm run verify`. التقرير بالقالب المعتاد. **مواعيد:** G2 اليوم 12:00، دفع أخير 22:00، تجميد G3 الاثنين صباحاً (بعده لا push إلا بإذن A). لا ميزات جديدة.

1. وثائق الآخرين التي تذكر `#/preview` (TOUCH_QA وNEXT_SAT وprompts/*): أذن لك بتعديل **الإشارة فقط** لتقول «يعمل على `npm run dev` فقط، وليس على الرابط المنشور». لا تغيّر غير ذلك.
2. بعد نشر Vercel التالي افتح (من حسابك أو أخبر مازن) `view-source` للرابط وتأكد من `og:image` (يبدأ بـ https). سجّل النتيجة في DEPLOY.md.
3. بعد كل دفعة صور: `npm run thumbs && npm run verify` وأبلغ بسطرين.
