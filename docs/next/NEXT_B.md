# NEXT_B — المحرّك والنشر (حساب GitHub)
## قبل ما تبدأ (دقيقتان)
1. استعمل نفس ملف START الذي استعملته أول مرة (نفس التوكن والـ clone). ما في إعداد جديد.
2. `git pull --rebase origin main` — **مهم**: الواجهة كلها تغيّرت (تصميم ريبلت) والـ jigsaw صار `#cell=n`.
3. اقرأ `docs/CONTRACT.md` §10 و`docs/LEVELS.md` (جدول فصلك) و`docs/SYMBOLS.md`.
4. اعمل فقط في مجلداتك. قبل كل push: `npm run typecheck` ثم `npm run check`. لا force-push.
5. بعد كل push ارسل لمازن: رقم الـ commit + قائمة بما اكتمل + أي سؤال (سطر واحد لكل سؤال).

## مهامك بالأولوية
1. **شاشة نتيجة البوس (l7):** بعد إكمال l7 في أي فصل اعرض قطعة الخريطة (`chapter.mapPiece`) ثم رمز الفصل (`symbol-cN`، انظر SYMBOLS.md). الرمز يُمنح **تلقائياً** عند إكمال البوس وليس عبر `reward`. الفصل 5 يعرض الخريطة الكاملة ثم يذهب إلى `#/ending`.
2. **الصوت والإعدادات:** WebAudio بنغمات بالكود (نقرة، نجاح، خطأ) + مفتاح كتم + حجم النص (1 / 1.15 / 1.3). زر الإعدادات في هيدر `ChapterSelect` و`LevelMap`. الحالة موجودة في `store.settings`.
3. **`scripts/optimize-images.mjs` (sharp):** يحوّل أي PNG/JPG داخل `public/art` إلى WebP: الخلفيات 1536×1024 بحد 250KB، الشخصيات 768×768 شفافة، الأيقونات 256×256. مازن سيشغّله بعد التوليد.
4. **`migrateV1`:** اقرأ مفتاح التخزين القديم لريبلت من `src/game/useGame.ts` (ملف مزال من المسار الجديد؛ راجعه من git history) وحوّل التقدّم إلى V2 عند أول فتح.
5. **النشر على Vercel:** مشروع Vite بجذر `artifacts/nile-secrets`، أمر البناء `npm run build`، المخرج `dist`. أنشئ `vercel.json` بسيط. جرّب الرابط على موبايل. اسأل مازن عن حسابه عند الحاجة فقط.
6. **جولة 375px:** افتح كل مستوى مع مازن (أو عبر Playwright) وسجّل كل خلل في `docs/BUGS.md` بصيغة: المستوى — الخلل — الخطورة.
