# NEXT6_B — حزمة التسليم
## قبل ما تبدأ
`git pull --rebase origin main`. نفس START. اعمل في ملفاتك فقط. قبل كل push: `npm run typecheck` ثم `npm run check` ثم `npm run test:content`. التقرير بالقالب المعتاد. **مواعيد:** السبت 22:00 كل شيء مدفوع، G2 الأحد 12:00، G3 الاثنين صباحاً تجميد. لا ميزات جديدة.

1. **`npm run verify`:** أمر واحد يشغّل بالترتيب: typecheck، check، test:content، test:unlock، test:migrate، فحص وجود المصغّرات لكل خلفية، report:assets (ملخص فقط)، ويطبع «كل شيء سليم» أو يقف عند أول فشل بسطر واضح. (لا e2e فيه لأنه يحتاج متصفحاً.) وثّقه في RELEASE_CHECKLIST.
2. **`README.md` في جذر المستودع** (للجامعة): ما هي اللعبة، كيف تُشغَّل محلياً (أوامر)، بنية المجلدات، كيف تُبنى وتُنشر (يشير إلى DEPLOY.md)، الاختبارات، الترخيص/الاعتمادات (الصور مولّدة بالذكاء الاصطناعي: صرّح)، وروابط الوثائق. عربي، صفحة واحدة تقريباً.
3. **أصول الصور القادمة:** تأكد أن `npm run thumbs` يتجاهل بهدوء الصور الناقصة ولا يفشل، وأن ترتيب البدائل (مصغّرة ثم خلفية ثم قديمة) لا يعرض صورة مؤقتة بعد وصول الحقيقية.
4. بعد أي push لصور أدفعها أنا، شغّل `verify` على main وأبلغ بنتيجة سطرين.
