# NEXT4_B — الفاحص وجودة الصور الحقيقية
## قبل ما تبدأ
`git pull --rebase origin main`. نفس START والتوكن. اعمل في ملفاتك فقط. قبل كل push: `npm run typecheck` ثم `npm run check` ثم `npm run test:content` (بعد آخر rebase). التقرير بالقالب المعتاد. **مواعيد:** السبت 22:00 كل شيء مدفوع، G2 الأحد 12:00 (35 مستوى تعمل)، G3 الاثنين صباحاً تجميد.
**قرارات A اليوم (ملزمة):** (1) تسمية المكافآت موحّدة: «قطعة الخريطة الأولى/الثانية/الثالثة/الرابعة»، والخامسة «الخريطة الكاملة». عدّلتُ ch2 وch4 بنفسي. (2) ممنوع أي رمز يظهر إيموجي ملوّناً على الهاتف (⚓ ♒ ⚘ ★ ☀ ✔ وأمثالها). استعملوا أشكالاً هندسية (▲ ◆ ■ ● ◐) أو حروفاً. (3) مشروع الـ100 مستوى مؤجَّل بعد التسليم؛ لا تبدأوا به. (4) قصة الاثنين: 35 مستوى، 5 فصول، لا نضيف ميزات جديدة بعد G2.

1. **الفاحص (scripts/check-content*.mjs):** أضف فحوصاً جديدة مع اختبارات ذاتية: (أ) تتابع الفصول 1..N بلا فجوات؛ (ب) تفرّد `mapPiece.id` بين الفصول؛ (ج) كل `character` وكل `speaker` موجود في CHARACTERS؛ (د) **رفض أي إيموجي** في label/text/detail (`\p{Extended_Pictographic}` مع استثناء الأشكال الهندسية المسموحة)، فإن فشل فالخطأ باسم المستوى. شغّلها على المحتوى الحالي وأبلغ بالنتيجة.
2. **playwright كـ devDependency** (طلب C): أضفها حتى يعمل `npm run test:e2e` على أي جهاز بعد `npm i`. تحقق أن البناء لا يتأثر. وثّق في RELEASE_CHECKLIST أمر واحد: `npm ci && npm run check && npm run test:content && npm run test:e2e`.
3. **فحص بصري للفصل الأول بالصور الحقيقية:** الصور الآن في `public/art/c1` و`chars` و`items`. افتح c1-l1..l7 على 375px و1280px، وصوّر كل مستوى. أبلغ: نص يُقرأ فوق الصورة؟ بطاقات الشخصيات تقطع الوجوه؟ أيقونات الجرار والقطع ظاهرة؟ أصلح ما كان في CSS/ملفات المحرك. أي مشكلة في المحتوى أو الصورة اكتبها لـA ولا تعدّلها.
4. **جاهزية العرض:** صفحة `#/` وخريطة الفصول بالصور الحقيقية: أرسل لقطات. تأكد من الأيقونات المفقودة (jar-dates وcalendar-page وold-photo) أنها تسقط بهدوء إلى نص/بديل ولا تظهر مربعاً مكسوراً.
5. (اختياري، فقط إن بقي وقت) تخزين مؤقت بسيط لتحميل أصول الفصل التالي مسبقاً بعد إكمال l7. لا service worker.
6. **تقرير الجامعة:** اكتب `docs/report/05_deployment_testing.md` (فصل «النشر والاختبار»): المعمارية المختصرة للنشر، الاختبارات الآلية الأربعة وما تغطيه، حدودها (ما لا تغطيه)، وقائمة الإصدار. عربي، 400–700 كلمة، صادق عمّا لم يُجرَّب على جهاز حقيقي.
