## مهامك
**قُبل شغل الواجهة. شكراً.** تعديلات صغيرة، ثم مهمة جديدة:
1. في `docs/dialect/UI_STRINGS.md`: «أوضة» صارت «غرفة» (عدّلتها أنا في `ChapterSelect.tsx`). أي «الحقيبة» متبقية في نصوص ظاهرة للاعبة تصير «الشنطة» (التعليقات تبقى).
2. **مهمة: شاشة «شوف الحكاية» (مقدمة اللعبة).** كل الأصول جاهزة في `public/intro/` (15 صورة webp بمقاس 1280×720 + `intro_timeline.json` + `intro_subtitles.vtt`) والتوثيق في `docs/intro/`.
   - زر «شوف الحكاية» في `TitleScreen` (لا تشغيل تلقائي). route جديد `#/intro`.
   - **منطق التشغيل (3 طبقات، كلها اختيارية ما عدا الأخيرة):**
     (أ) لو وُجد `/intro/intro.mp4` (تحقق بـ HEAD أو `onError`): شغّله بـ `<video playsInline>` مع ترجمة `intro_subtitles.vtt` (`<track>`) وعناصر تحكم بسيطة؛
     (ب) وإلا شغّل **مشغّل المشاهد**: مرّ على `scenes` في `intro_timeline.json` حسب `start/end` (ثواني)، اعرض `image` (من `/intro/`) أو `/intro/{clip}` إن وُجد، بحركة تقريب CSS (Ken Burns) ونص الترجمة `subtitle` من الـ JSON، ويشغّل `/intro/music.mp3` (إن وُجد) و`/intro/sfx/{sfx}` (إن وُجد) — الملفات الصوتية قد لا تصل، فتجاهل غيابها بصمت؛
     (ج) الترجمة نص HTML حقيقي RTL (ليست مرسومة)، بخلفية شبه شفافة وتباين جيد، والحجم مناسب لـ 360px.
   - زر «تخطّي» ظاهر دائماً (≥44px). عند الانتهاء أو التخطّي: ارجع للعنوان واحفظ `localStorage` مفتاح `nile-intro-seen` (try/catch). الصوت يبدأ بضغطة المستخدم (زر الشاشة).
   - `prefers-reduced-motion`: بلا Ken Burns. لا شيء يُحمَّل قبل الضغط (الصور lazy، video `preload="none"`).
   - أي فشل (404/خطأ) → ارجع للعنوان بهدوء ولا تكسر اللعبة. أضف حالة E2E واحدة (الزر يفتح #/intro، التخطّي يرجع).
   - **مخاطرة:** هذا ما بعد التجميد المريح؛ ادفع فقط إن مرّ `npm run verify` وE2E (C يشغّله). إن لم يكتمل بحلول 21:00 اتركه (لا تدفع شيئاً ناقصاً).
3. وبعدها `npm run thumbs && npm run verify` وبلّغني.
