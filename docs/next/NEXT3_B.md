## قبل ما تبدأ
`git pull --rebase origin main`. نفس START والتوكن. اعمل في ملفاتك فقط. قبل كل push: `npm run typecheck` ثم `npm run check` ثم `npm run test:content` (بعد آخر rebase). ارسل التقرير بالقالب. **مواعيد:** أول دفعة السبت 14:00، الكل السبت 22:00، G2 الأحد 12:00.
**كل المستويات الـ35 موجودة الآن. من هنا الشغل: جودة، اختبار، توثيق. الصور تصل من مازن قريباً.**

1. **ErrorBoundary** حول اللغز والشاشات: لو انهار مكوّن تظهر رسالة هادئة + زر «العودة للخريطة» (لا شاشة بيضاء). سجّل الخطأ في console. اختبره بإلقاء خطأ عمداً في demo ثم أزله.
2. **حجم الحزمة:** تأكد أن كل لغز chunk كسول، وأن الصفحة الأولى (`#/`) لا تحمّل الألغاز. أبلغ بأحجام الـ chunks الأكبر. صور legacy الخمس (~600KB) تُحمَّل عند الحاجة فقط.
3. **`docs/RELEASE_CHECKLIST.md`:** قائمة فحص قبل التسليم (البناء، الاختبارات الثلاثة، رابط Vercel، فتح 15 مستوى A على موبايل، مسح التخزين، وضع الخصوصية، فصل عن الإنترنت بعد أول تحميل، الصوت، حجم النص). مازن يمرّ عليها يوم الأحد.
4. **زر «بدء من جديد» والترحيل:** تأكد أن إعادة الحكاية تمسح V2 ولا تعيد ترحيل V1 تلقائياً بعدها.
5. **أي صور جديدة:** أنا أحوّلها وأضعها. لا تشغّل optimize-images عليها.
