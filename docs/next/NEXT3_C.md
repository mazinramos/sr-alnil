## قبل ما تبدأ
`git pull --rebase origin main`. نفس START والتوكن. اعمل في ملفاتك فقط. قبل كل push: `npm run typecheck` ثم `npm run check` ثم `npm run test:content` (بعد آخر rebase). ارسل التقرير بالقالب. **مواعيد:** أول دفعة السبت 14:00، الكل السبت 22:00، G2 الأحد 12:00.
**كل المستويات الـ35 موجودة الآن. من هنا الشغل: جودة، اختبار، توثيق. الصور تصل من مازن قريباً.**

**المهمة:** `scripts/e2e-playthrough.mjs` (Playwright، 375px، tap) + `npm run test:e2e`:
1. يبدأ من تقدّم فارغ ويمرّ على **المستويات الـ35 بالترتيب عبر الواجهة فقط**، ويحلّ كل مستوى بحلّه من `config` نفسه (حلّال لكل نوع من الـ12؛ لا تضع الحلول يدوياً).
2. بعد كل مستوى يتحقق: ظهرت بطاقة النتيجة، والمستوى التالي فُتح، ولا أخطاء JS. بعد كل l7 يمرّ على شاشة المكافأة. في النهاية يصل إلى `#/ending`.
3. يشغّل أيضاً سيناريو «حل خاطئ ثم صحيح» لخمسة مستويات عشوائية (يتحقق من النجوم 1–3).
4. اطبع جدولاً: المستوى — النتيجة — الزمن. أي فشل = exit 1.
5. أي خلل يظهر في ألغاز غيرك: سجّله في `docs/TOUCH_QA.md` للمالك ولا تعدّل ملفاته. (route وbalance وmemory تتأخر 0.7–0.9 ث: مقبولة.)
6. صور c1/l1 الفعلية ستصلك قريباً من مازن لضبط إحداثيات hotspot. انتظرها ولا تؤجل بقية المهمة.
