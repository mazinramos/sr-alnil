# NEXT5_B — جاهزية الأجهزة الحقيقية
## قبل ما تبدأ
`git pull --rebase origin main`. نفس START. اعمل في ملفاتك فقط. قبل كل push: `npm run typecheck` ثم `npm run check` ثم `npm run test:content`. التقرير بالقالب المعتاد. **مواعيد:** السبت 22:00 كل شيء مدفوع، G2 الأحد 12:00 (35 مستوى تعمل)، G3 الاثنين صباحاً تجميد. لا ميزات جديدة.
**قرارات A:** (1) لهجة آدم وسيف الخفيفة تبقى كما أبقاها D؛ الدلائل والأهداف والتلميحات والراوي وكلام نور ورحاب فصحى. (2) الإجمالي 101 صورة؛ carve-smooth تبقى اختيارية (B). (3) c3-l2: بضاعة الدكاكين الموحية تبقى غير مقروءة، لا تغيير. (4) صور ch2..ch5 تصل من مازن مساء السبت والأحد؛ كل مستوى بلا صورة يسقط إلى البديل القديم (مقبول للتسليم).

1. **سلامة التخزين:** لو `localStorage` غير متاح (وضع خصوصي) أو ممتلئ أو أعاد JSON تالفاً: اللعبة تبدأ بتقدّم فارغ وتعمل في الذاكرة دون انهيار، وتظهر رسالة صغيرة «التقدّم لن يُحفظ في هذا الوضع». اختبر الثلاث حالات بمحاكاة، وأضفها كسيناريو في اختبار الترحيل.
2. **الوصول والمس:** كل أزرار اللعبة ≥44px، حالة `:focus-visible` ظاهرة، `aria-label` عربي لأزرار الأيقونات (إغلاق، دفتر، مخزن، تلميح)، واحترم `prefers-reduced-motion`. أبلغ بما أصلحت.
3. **أداء الشبكة البطيئة:** `loading="lazy"` أو ما يناسب لصور غير الشاشة الحالية، وتأكد أن مستوى واحداً لا يحمّل أكثر من ~700KB صور. أبلغ بأثقل 3 مستويات (حجم الصور الفعلي من `public/art`).
4. **`npm run report:assets`** وحدّث MISSING_ASSETS.md، واكتب في RELEASE_CHECKLIST سطراً: ما يُشغَّل بعد كل دفعة صور.
5. **Vercel:** راجع DEPLOY.md خطوة خطوة كأنك مازن لا يعرف شيئاً: هل كل أمر موجود؟ هل `vercel.json` أو إعداد SPA مطلوب مع hash router؟ هل بناء `dist` يعمل من مجلد `artifacts/nile-secrets` كـ Root Directory؟ أصلح النواقص في الملف نفسه.
