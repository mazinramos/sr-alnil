# NEXT8_B — لمسات الإصدار
## قبل ما تبدأ
`git pull --rebase origin main`. اعمل في ملفاتك فقط. قبل كل push: `npm run verify` (أو typecheck + check + test:content). التقرير بالقالب المعتاد. **مواعيد اليوم (الأحد 1/11):** G2 الساعة 12:00 (كل المستويات تعمل على الرابط)، ودفع أخير الساعة 22:00، وتجميد G3 الاثنين صباحاً. بعد التجميد لا push إلا بإذن A. لا ميزات جديدة.
**قرار توحيد التصريح (ملزم لكل فصل تقرير):** أول سطر في ملفك بالضبط:
> **تصريح:** كُتب هذا الفصل بمساعدة نموذج ذكاء اصطناعي (Claude، حساب [الحرف] في فريق من ستة حسابات) تحت إشراف الفريق ومراجعته. ما ورد فيه عن النتائج هو ما نُفِّذ فعلاً، وما لم يُجرَّب مذكور في فقرة الحدود.
وأزل أي «الطالب/الطالبة» واكتب «الفريق». المشروع مشروع مازن وفريقه.

1. **أخفِ أدوات المطوّر من النسخة المنشورة:** `#/preview` و`#/preview/coords` تعمل فقط في وضع التطوير (`import.meta.env.DEV`)؛ في الإنتاج تعيد إلى `#/`. تأكد أن `check` وE2E (لا يعتمد عليها) يمرّان.
2. **واجهة المشاركة:** `favicon` (من `symbol-c1` أو الشمس)، وسوم `og:title`/`og:description`/`og:image` (استعمل `public/art/ui/title.webp` مصغّراً ≤200KB)، و`theme-color`، و`<noscript>` عربي قصير. لا مكتبات جديدة.
3. **رابط غير موجود:** `#/` + أي مسار مجهول يعيد لشاشة هادئة فيها زر «العودة للخريطة» لا شاشة فارغة (اختبره).
4. **05_deployment_testing.md:** وحّد التصريح (أعلاه) وأزل «الطالبة».
5. بعد كل دفعة صور أدفعها: `npm run thumbs && npm run verify` وأبلغ بسطرين.
