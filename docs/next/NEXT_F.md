# NEXT_F — مدير الفن: برومبتات الدفعات 2–5 + تعديل الخريطة (لا كود)
## قبل ما تبدأ (دقيقتان)
1. استعمل نفس ملف START الذي استعملته أول مرة (نفس التوكن والـ clone). ما في إعداد جديد.
2. `git pull --rebase origin main` — **مهم**: الواجهة كلها تغيّرت (تصميم ريبلت) والـ jigsaw صار `#cell=n`.
3. اقرأ `docs/CONTRACT.md` §10 و`docs/LEVELS.md` (جدول فصلك) و`docs/SYMBOLS.md`.
4. اعمل فقط في مجلداتك. قبل كل push: `npm run typecheck` ثم `npm run check`. لا force-push.
5. بعد كل push ارسل لمازن: رقم الـ commit + قائمة بما اكتمل + أي سؤال (سطر واحد لكل سؤال).

## مهامك بالأولوية
1. **أولاً وفوراً:** اقرأ `docs/prompts/NOTE_MAPFULL_CELLS.md` وعدّل برومبت `ui-map-full` في PROMPTS_01 (وكل ما يذكر strip/الشرائح في PROMPTS_00 وPROMPTS_01 يصير cell/الخلايا). **مازن لن يولّد الخريطة قبل ذلك.**
2. **PROMPTS_02_CH2.md** ثم **PROMPTS_03_CH3.md** ثم **PROMPTS_04_CH4.md** ثم **PROMPTS_05_CH5.md** (بنفس صيغة CH1: اسم الملف الحرفي، المقاس، الأسلوب، برومبت كامل بالإنجليزية). ابدأ بخلفيات **الطبقة A** (l1 وl4 وl7 لكل فصل) ثم الباقي. الخلفيات 1536×1024.
3. **حزمة صغيرة لمازن:** ملف `docs/prompts/GENERATION_ORDER.md` فيه ترتيب التوليد الأمثل لأول 35 صورة (map-full، ثم خلفيات الطبقة A، ثم الشخصيات الـ6 الجديدة، ثم الأيقونات)، وماذا يفعل إن أخرج جيمناي نتيجة غير مناسبة (برومبت بديل مختصر لكل نوع).
4. **اتساق الشخصيات:** برومبت مرجعي موحّد لكل شخصية (وجه، لباس، ألوان) يُلصق مع كل تعبير. الشخصيات: بشير، صفية، آدم، سيف، يونس، حليمة، هالة، الحاج عثمان، رحاب (ونور موجودة).
5. **ما يتغيّر:** رموز الفصول الخمسة (symbol-c1..c5) كأيقونات 256×256 بنفس أسلوب SYMBOLS.md.
