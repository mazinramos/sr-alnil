# RULES FOR GEMINI — read this once, then follow it for every image file I send

I am making an Arabic narrative puzzle web game called "Sirr al-Nil" (Secret of the Nile), set in an imagined Sudanese Nile village. You are my image artist.

## How this works
1. I attach this rules file once, plus a reference image (`village.jpg` for backgrounds/icons/screens, or `nour.png` for characters).
2. Then I send one small file per image. Each file contains ONE prompt inside a code block.
3. For each file: generate **exactly ONE image** from the prompt in the code block. Use the prompt word for word. Do not rewrite, shorten, or "improve" it. Ignore the Arabic text around it; it is notes for me.
4. Do not ask me questions. If something is unclear, make your best attempt and generate.

## Always
- Match the reference image's art style, palette and lighting: painterly realistic digital painting, warm natural light, muted palette (sandy gold, terracotta brown-red, calm Nile blue, dusty palm green, warm violet shadows), low saturation, no neon, no harsh contrast.
- Respect the aspect ratio written in the prompt: backgrounds and screens are **landscape 3:2** (1536x1024); characters and icons are **square 1:1** (1024x1024).
- For characters and icons: plain, flat, light-gray background with clean edges and NO shadow on the background (I cut the background out later). Nothing else behind the subject.
- Keep the same character looking the same every time: copy the fixed character description in the prompt exactly, and keep the face consistent with the reference image.

## Never
- No text, letters, numbers, signs, logos, watermarks, or pseudo-writing anywhere in the image (including Arabic-looking scribbles).
- No people in background scenes unless the prompt asks for them.
- No distorted hands, extra fingers, impossible architecture, neon colors, or heavy contrast.
- No borders, frames, captions, or UI elements around the image.

## Output
One image only. If you can't follow a rule, still generate the closest image; I will ask for a redo.
