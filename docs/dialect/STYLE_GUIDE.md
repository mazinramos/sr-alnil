# دليل اللهجة السودانية + قواعد وضوح الألغاز (قرار مازن، 1/11)

**القرار:** كل نصوص اللعبة بالدارجي السوداني (نور والجميع، والدلائل والتلميحات والواجهة). ومازن حاسّي إنو الألغاز ملخبطة، فالتحويل فرصة نوضّحها. **ما بنغيّر منطق أي لغز.**

## 1) ممنوع تلمسو (هذا يكسر الاختبارات)
- أي `id`، `puzzle.*` (solution, correct, cipherText, answer, key, targets/coords, nodes, pairs…)، `difficulty`، `background`، `character`، أسماء المتحدّثين (نور، بشير…)، `reward.id`، `mapPiece.label` («قطعة الخريطة الأولى…» تبقى كما هي).
- **الإجابات حرفياً:** نص الشفرة وإجابتها يبقيان كما هما حرفاً حرفاً. لو دليل بيذكر كلمة الحل، تُكتب بنفس الحروف.
- مسموح: `title`, `dialogue[].text`, `objective`, `clues[].title/text/source`, `hints[]`, `successText`, عناوين الفصل/`location`/`summary`، و`label`/`detail` للعناصر (بشرط أن الدلائل تستخدم نفس الكلمة بالضبط).
- قيود الفاحص (`npm run test:content`): الحوار 2–4 أسطر، التلميحات 3 بالضبط، الدلائل 2–3، بلا إيموجي (استخدم ▲ ◆ ■ ● فقط).

## 2) اللهجة: قواعد مختصرة
خرطومية/أمدرمانية مفهومة، جمل قصيرة، دافئة. الكتابة بحروف عربية عادية (ق تبقى ق، ما بنكتب g).

| فصحى | سوداني | | فصحى | سوداني |
|---|---|---|---|---|
| الآن | هسّه | | أين | وين |
| ماذا | شنو | | لماذا | ليه |
| من (سؤال) | منو | | متى | متين |
| هذا/هذه/هؤلاء | دا / دي / ديل | | ذلك | داك / داكي |
| أريد | عايز / عايزة | | لا يوجد / يوجد | ما في / في |
| سوف أفعل | حا/ح: حاعمل، حنمشي | | أيضاً | كمان / برضو |
| فقط | بس | | جداً | شديد / كتير |
| لأن | عشان / لأنو | | إذا | لو |
| يجب | لازم | | ما زال | لسه |
| حسناً | طيب / تمام / ماشي | | نعم | أيوا |
| ضوء | ضو | | جدار/حائط | حيط |
| نافذة | شباك | | طائر | طيّر |
| ثلاثة/ثمانية | تلاتة / تمانية | | ثقيل/ثاني | تقيل / تاني |
| ولد/بنت | ولد / بت | | الجدّة | **حبوبة** (حبوبة صفية) |
| ابحثي/اعثري | دوّري / لقّي | | انظري | شوفي |
| اقرئي | اقري | | تذكّري | افتكري |
| حاولي | جرّبي | | أحسنتِ | عاش / برافو عليك |

- **الفعل:** أنا بشوف / إنتَ بتشوف / إنتِ بتشوفي / هو بيشوف / نحن بنشوف / ديل بيشوفوا. المستقبل: حاشوف، حتشوفي، حيشوف. الماضي: شفت، شفتي، شاف، شفنا. النفي بـ«ما» فقط: ما شفت، ما بشوف، ما في (لا «مش» ولا «ما…ش»).
- **الضمائر:** كتابو، بيتها، دفترك، ليهو، ليها، ليك، معاهو، منّو، فيها. الأمر للمؤنّث لنور: اقري، شوفي، دوّري، فكّري، ركّزي.
- **الموصول:** «الـ+الفعل» أو «البـ…»: «المكان البشبهها»، «الزول الجا امبارح». بلا «اللي».
- **نداء/نكهة خفيفة (بلا مبالغة):** يا بتي، يا ولدي، يا زول، والله، خلاص، يلا، ما تشيلي هم، الله يكرمك. مرّة أو مرّتين في الحوار، لا في كل سطر.
- **ممنوع** ألفاظ مصرية/خليجية/شامية: إزاي، ده، كده، دلوقتي، أوي، مش، فين، إيه، وايد، شلون، هلأ، شو، ليش.
- **الشخصيات:** نور: بنت مدينة راجعة لبيت جدّتها، لهجة خرطومية خفيفة ومتعلّمة. بشير ويونس: أكبر وأثقل في اللهجة. هالة: عملية ومباشرة. الحاج عثمان: كبير وهادئ. دفتر حبوبة صفية (الاقتباسات): نفس الدارجي لكن بنبرة كبار السن، قصيرة وفيها حكمة.
- **الواجهة:** أزرار قصيرة، فعل أمر: «جرّب تاني»، «تلميح»، «ارجع للخريطة». (B يحدّد القائمة.)

## 3) قواعد وضوح الألغاز (هذا الجزء الأهم)
1. **`objective` جملة واحدة بفعل صريح:** رتّبي / وصّلي / اختاري / دوّري / افتحي القفل… وتقول بالضبط الشغلة شنو والنتيجة شنو.
2. **كل دليل معلومة واحدة** في جملة ≤ 20 كلمة، وبنفس كلمات الشاشة (نفس أسماء العناصر والمحطات). ما نكتب «ذاك الشيء»؛ نكتب اسمو.
3. **الدليل اللغزي (اقتباس من الدفتر):** نكتب الاقتباس بالدارجي ثم سطراً بسيطاً بعدو: «يعني: …» يشرح المعنى بكلام عادي من غير ما يعطي الحل.
4. **التلميحات تتصاعد:** (1) من وين أبدأ / وين أنظر، (2) خطوة أضيق تستبعد شيئاً، (3) تقريباً الحل (الإجابة إلا اللمسة الأخيرة).
5. **لا معرفة من خارج الشاشة:** لو الحل يحتاج حاجة ما مكتوبة، أضفها للدليل.
6. **اختبار الحل الوحيد (إلزامي لكل مستوى):** حلّه بالقلم باستخدام النصوص الظاهرة فقط (الهدف + الدلائل + أسماء العناصر). لو طلع أكثر من حل، أو خطوة غامضة، أصلحها **بالصياغة**. لو ما ينفع بالصياغة، لا تغيّر الحل: **بلّغ A** باسم المستوى والمشكلة.
7. لا تجمّل: الكلمة البسيطة المعروفة أحسن من الدارجي الغريب. لو كلمة سودانية ممكن غير السوداني ما يفهمها، اختار الأوضح.

### قبل/بعد (للمعايرة)
| قبل | بعد |
|---|---|
| «أشعر أنها تنتظرني. يقول الدفتر إن في الغرفة ثلاث علامات مخبّأة.» | «حاسّة إنها بتنتظرني. الدفتر بيقول في تلاتة علامات مخبّأة في الغرفة.» |
| الهدف: «اعثري على العلامات الثلاث المخبّأة…» | «دوّري على العلامات التلاتة المخبّأة في الغرفة: قرص الشمس والطيّر وقطعة المركب. ولمسي كل علامة لمن تلقيها.» |
| دليل: «الشمس تُنقَش عالياً في الجدار، حيث لا يصل الضوء.» | دليل: «الشمس بتتنقش فوق في الحيط، في مكان ما بيصلو الضو.» — يعني: دوّري فوق، في ركن مظلم.» |
| تلميح: «اقرئي أسطر الدفتر مرّة أخرى.» | تلميح: «اقري الدفتر تاني، سطر سطر. كل سطر بيقول ليك نوع المكان البتتخبّى فيهو العلامة.» |
| نجاح: «ما كان يبدو مبعثراً صار له أصل معروف.» | نجاح: «الحاجات الكانت مبعثرة هسّه كل واحدة عرفنا أصلها.» |

## 4) خطوات كل مستوى (لكل حساب)
1. اقرأ المستوى كاملاً (النص + `puzzle`) وفهم الحل.
2. أعد كتابة النصوص المسموح بها بالدارجي مع قواعد الوضوح.
3. نفّذ اختبار الحل الوحيد (البند 3.6).
4. بعد كل فصل/مجموعة: `git pull --rebase origin main` ثم `npm run dialect` (الهدف: نظيف أو ملاحظات مقصودة فقط) ثم `npm run verify` ثم push.
5. ادفع بعد كل فصل أو 3 مستويات (لا تنتظر النهاية). أي مستوى لم يُحوَّل يبقى يشتغل كما هو.
6. لا تغيّر ملفات خارج ملفاتك. لو وجدت خطأ في ملف غيرك بلّغ.

`npm run dialect` يلقط الفصحى والعامّيات غير السودانية في حقول النص فقط (ليس تحقّقاً نهائياً: أنتم المرجع).

## 6) قرارات توحيد الكلمات (A، 1/11 مساءً)
- **الموية** (لا «الماء») في كل النصوص والتسميات: خابية موية، خط الموية.
- **الغرفة** (لا «أوضة»). **الشنطة** (لا «الحقيبة»). **حبوبة** (لا «الجدة»). **الطيّر** (لا «الطائر»).
- **الشباك** = النافذة (للشباك في الصيد استعمل «الشبكة»).
- أزرار اللاعبة بصيغة المؤنث (ارجعي، جرّبي، خلّصي) حسب العقد.
- حرف ق يبقى «ق» كتابةً.
