# UI_STRINGS.md — نصوص الواجهة: القديم ← الجديد (دارجي سوداني)

> مولَّد من خريطة التحويل التي طُبّقت في الكود. للمراجعة: اكتبوا بجانب أي سطر تريدون تغييره. الألفاظ المفتاحية موحّدة: **دفتر حبوبة صفية** (الدفتر)، **الشنطة** (الحقيبة)، **ارجعي للخريطة**، **المستوى الجاي**. الخطاب بالمؤنث للاعبة (اختاري، شوفي، جرّبي)، ومسميات الأزرار القصيرة على الأمر المؤنث (انتبهوا: دليل A يمثّل بصيغة المذكر «جرّب تاني»، وبقيت على المؤنث لتوافق قاعدة العقد §0).

## ما لم يتغيّر عمداً
- **المفاتيح والمنطق:** مفاتيح localStorage، المعرّفات، المسارات (routes)، `aria-label` المستعملة كسلكتورات في الاختبارات بقيت إلا ما ذُكر أدناه.
- **أسماء الشخصيات**، وأسماء الرموز (الشمس/الموجة/الميزان/العين/الخيط)، و`mapPiece.label`.
- أزرار محايدة مفهومة كما هي: «تأكيد»، «افتحي»، «مسح»، «مسح الكل»، «حذف»، «تدوير»، «تبديل»، «الخاتمة»، «قطعة الخريطة»، «ابدئي الرحلة».
- صفحتا المطوّر `#/preview` و`#/preview/coords` (تعملان مع `npm run dev` فقط ولا يراهما اللاعب).
- عناوين الفصول وملخّصاتها وكل نصوص المستويات: عند أصحاب الفصول (`content/chapters`).
