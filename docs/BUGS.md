# BUGS.md — جولة 375px (B)

الجولة آلية: Chromium بدون واجهة، عرض 375×812 بلمس، على نسخة `npm run build` المحلية، مع تقدّم مفتوح بالكامل. غطّت 47 مساراً: العنوان، الخريطة، 5 عقد فصول، 35 مستوى، 5 شاشات مكافأة، الخاتمة، المعاينة.
**لم تُغطِّ:** جهازاً حقيقياً، تفاعل الحل داخل الألغاز، الصوت. كلها تحتاج مازن.

صيغة السطر: المستوى — الخلل — الخطورة.

## نتائج
- كل المسارات الـ47 — تمرير أفقي عند 375px — لا يوجد ✓
- كل المسارات — أخطاء JS أو صفحات تنهار — لا يوجد ✓ (الخطأ الوحيد في الـ console هو تحميل خط Google Fonts، لأن بيئة الاختبار بلا إنترنت)
- c1-l4, c1-l7, c2-l4, c2-l7, c3-l4, c3-l7, c4-l4, c4-l7, c5-l1, c5-l4 — ملف الخلفية `/art/cN/lM.webp` غير موجود بعد (يظهر البديل) — متوسط، ينتظر الصور
