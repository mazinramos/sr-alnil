# DEPLOY.md — نشر «سر النيل» على Vercel (لمازن)

لا تحتاجين معرفة سابقة بـ Vercel. الموقع كله ملفات ثابتة (لا سيرفر)، فالنشر بسيط. الوقت المتوقع: 10 دقائق.

## قبل أن تبدئي
- الريبو `mazinramos/sr-alnil` على GitHub، والكود في `artifacts/nile-secrets/`.
- افتحي `npm run check` محلياً داخل `artifacts/nile-secrets/` وتأكدي أنه ينتهي بدون أخطاء. لو فشل لن ينجح النشر أيضاً.

## الربط (مرة واحدة)
1. ادخلي إلى vercel.com وسجّلي الدخول بحساب **GitHub** نفسه (زر Continue with GitHub).
2. اضغطي **Add New…** ثم **Project**.
3. اختاري الريبو `sr-alnil` واضغطي **Import**. إن لم يظهر: اضغطي **Adjust GitHub App Permissions** وأعطي Vercel صلاحية على هذا الريبو فقط.
4. في صفحة الإعدادات اضبطي هذه الحقول بالضبط:
   | الحقل | القيمة |
   |---|---|
   | Framework Preset | **Vite** |
   | **Root Directory** | اضغطي Edit واختاري `artifacts/nile-secrets` |
   | Build Command | `npm run build` |
   | Output Directory | `dist` |
   | Install Command | `npm install` |
   (الملف `vercel.json` داخل المجلد يضع نفس القيم تلقائياً، لكن تأكدي منها بعينك.)
5. **لا تضيفي** أي Environment Variables الآن. Firebase مؤجَّل ولا يحتاج شيئاً.
6. اضغطي **Deploy** وانتظري دقيقة أو دقيقتين حتى تظهر الشاشة الخضراء، ثم اضغطي على الصورة لتفتح الرابط (شكله `https://sr-alnil-xxxx.vercel.app`).

## بعد الربط
أي `git push` إلى فرع `main` ينشر نسخة جديدة تلقائياً خلال دقيقة أو اثنتين. الرابط لا يتغيّر. نسخ الفروع الأخرى تأخذ روابط تجريبية منفصلة.

## كيف تتأكدين أن النشر سليم (على الموبايل)
افتحي الرابط الرئيسي ثم اختبري بالترتيب:
1. **الشاشة الأولى** تظهر بالعربية من اليمين لليسار، بلا نص إنجليزي، ولا صورة مكسورة، وعنوان التبويب «سرّ النيل».
2. اضغطي زر البداية فتفتح خريطة الرحلة. المحطة الأولى مفتوحة والباقي مقفل.
3. افتحي المستوى الأول وحلّيه. تأكدي من ظهور النجوم وزر «المستوى التالي».
4. **أغلقي التبويب كلياً وافتحي الرابط من جديد**: يجب أن يبقى التقدّم محفوظاً.
5. لا يوجد تمرير أفقي في أي شاشة، والأزرار تُضغط بسهولة بإصبع واحد.
6. جرّبي من **هاتفين مختلفين** (أندرويد وآيفون إن أمكن) وتأكدي من الصوت: يبدأ بعد أول لمسة، وزر الإعدادات يكتمه.

## لو ظهرت مشكلة
| العَرَض | السبب المحتمل والحل |
|---|---|
| Build Failed | افتحي Deployment ثم Build Logs وانسخي آخر سطور الخطأ لحساب B. غالباً `npm run check` يفشل محلياً أيضاً |
| صفحة بيضاء | تأكدي أن Root Directory هو `artifacts/nile-secrets` وليس جذر الريبو |
| 404 على كل شيء | تأكدي أن Output Directory هو `dist` |
| صور مكسورة | الملف غير موجود في `public/art`. راجعي `docs/MISSING_ASSETS.md` |
| الخط عادي لا عربي جميل | يحتاج إنترنت لتحميل خط Google Fonts؛ جرّبي شبكة أخرى |

## قبل التسليم النهائي (الاثنين)
- بعد تجميد الكود (G3) انشري آخر `main`، وأعيدي قائمة الفحص أعلاه كاملة على هاتفين.
- أرسلي الرابط النهائي لـ A مع ملاحظة أي خلل متبقٍّ.
